# AGENTS.md

Trilha de estudos de Java (2024) consolidada com `git subtree`. Cada pasta numerada é um exercício
independente, sem build compartilhado.

Leia [specs/README.md](specs/README.md) antes de alterar o repositório.

- Não reescreva o código dos exercícios: o valor do repositório é mostrar o ponto de partida. Correções
  de compilação (nome de arquivo) são aceitas; melhorias vão para a seção "O que eu faria diferente hoje" do README.
- Mantenha o histórico importado: não faça rebase nem squash dos commits de `git subtree`.
