# 02 · Estruturas de controle

Exercícios de decisão e repetição (antigo repositório `semana3`).

| Tema | Arquivos |
|---|---|
| Decisão | `If`, `IfElse`, `IfElseIf`, `SwitchComBreak`, `SwitchSemBreak` |
| Repetição | `For1`, `For2`, `WhileDeterminado`, `WhileIndeterminado`, `DoWhile` |
| Desvio de fluxo | `Break`, `BreakRotulado`, `Continue`, `ContinueRotulado` |
| Desafios | `desafioDiaSemana`, `desafioFor`, `desafioWhile` |
| Exercícios | `exAnoBissexto`, `exJogoAdivinhação`, `exNotas`, `exNumeroPar`, `exNumeroPrimo`, `exNumeroPrimoSwitch`, `exSomaNumerosPositivos` |

## Como executar

```bash
javac -encoding UTF-8 -d out exNumeroPrimo.java
java -cp out semana3.exercicios.exNumeroPrimo
```
